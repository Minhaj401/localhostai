# README media

- `chat.png`, `models.png`, and `server.png` are rendered from the actual Flutter
  application at 412 × 915, with 1.3× text scaling and illustrative test data.
  Capture them with `LOCALHOST_UI_PREVIEW_DIR=/path/to/output flutter test
  test/ui_design_test.dart` from `app/`.
- `architecture.svg` illustrates the Rust coordinator, managed laptop inference,
  Flutter client, and optional phone RPC worker. It contains no performance data.
- The brand lockup is referenced directly from `app/assets/logo/lockup.png`.
  Its provenance is recorded in `app/assets/logo/provenance.json`.
- The narrated 1080p demo is a native GitHub attachment in
  [Project demo](https://github.com/Minhaj401/localhostai/issues/1). The source
  composition is in `demo-video/`.
